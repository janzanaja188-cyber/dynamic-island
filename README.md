# ⏱️ Screen Time Stats

รู้ว่าวันนี้คุยกับบอทไปนานแค่ไหน แล้วใครครองอันดับหนึ่งของสัปดาห์ ✨

## เปิดดูยังไง
กดไอคอนไม้กายสิทธิ์ข้างช่องพิมพ์ → เลือก **เวลาบนหน้าจอ**
เท่านี้เลยค่ะ การ์ดจะเด้งขึ้นมากลางจอ

## ในการ์ดมีอะไร
- **กำลังนับอยู่** — นาฬิกาเดินสดของห้องที่เปิดอยู่ วงแหวนรอบตัวเลขคือความคืบหน้าของเป้าหมายวันนี้
- **รวม 7 วัน** — ยอดนาทีทั้งหมด พร้อมป้ายเทียบสัปดาห์ก่อน ▲ ขึ้น ▼ ลง
- **รายวัน** — กราฟแท่ง แตะแท่งไหนก็ได้เพื่อดูเลขของวันนั้น แท่งขวาสุดคือวันนี้
- **อันดับ** — โพเดียมสามอันดับแรก สลับดูได้ระหว่าง *คุยนานสุด* กับ *ข้อความเยอะสุด*

## เวลานับตอนไหน
เริ่มนับตอนเปิดห้องแชทค้างไว้ แล้วหยุดเองเมื่อ
- สลับไปแอปอื่นหรือปิดจอ → หยุดทันที
- ทิ้งไว้เฉย ๆ นานเกินเวลาที่ตั้งไว้ → หยุดพัก ขยับใหม่ก็นับต่อ
- เปลี่ยนไปคุยตัวอื่น → ปิดยอดตัวเก่า เริ่มนับตัวใหม่

ส่วนข้อความจะนับแค่ฝั่งบอทค่ะ ปัดหาคำตอบใหม่กี่รอบก็ไม่บวกเพิ่ม ตัวเลขจะได้ตรงจริง

## ตั้งค่า
Extensions → **⏱️ Screen Time Stats**
- *หยุดนับเมื่อไม่มีการขยับนาน* — เลือกได้ 1–60 นาที ค่าเริ่มต้น 5
- *เป้าหมายรายวัน* — กำหนดว่าวงแหวนจะเต็มที่กี่นาที
- *ซ่อนชื่อตัวละครในอันดับ* — เปิดก่อนแคปแชร์ให้เพื่อนดู
- *เปิดลูกเล่นและอนิเมชัน* — อยากได้แบบเรียบ ๆ ก็ปิดได้

## ข้อมูลเก็บไว้ตรงไหน
เก็บในไฟล์ตั้งค่าของบัญชีเราเองค่ะ ปิดแท็บ ล้างแคช หรือย้ายเครื่องก็ยังอยู่
สีทั้งหมดดึงจากธีมที่ใช้อยู่ เปลี่ยนธีมทีเดียวเปลี่ยนตามทั้งการ์ด 🎨

## ติดตั้ง
Extensions → Install Extension → วางลิงก์รีโพนี้ → รีเฟรชหนึ่งครั้ง
